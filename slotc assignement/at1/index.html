Choose the proper semantic element for navigation

<nav class="main-menu"> Semantic Landmark
<ul>
<li><a href="/">Home</a></li>
<li><a href="/features">Features</a></li>
</ul>
</nav>
Screen Reader & Accessibility Impact: Screen readers recognize <nav> as a landmark region, allowing visually impaired users to jump straight to site navigation. Generic <div> provides zero semantic meaning.
